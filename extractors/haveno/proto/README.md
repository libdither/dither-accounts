# Haveno's gRPC schema

`grpc.proto` and `pb.proto` are copied unchanged from haveno-reto, the Haveno network the node is on, at the
tag the node runs (docs/haveno.md says how to update them). Haveno, and Bisq before it, are free software under the
GNU Affero General Public License, version 3 or later; `grpc.proto` keeps Bisq's notice, and `pb.proto` comes under
the same licence. The repository's [LICENSE](../../../LICENSE) is that licence's text.

The extractor only loads these files to speak to a node; nothing is generated from them into this repository.
